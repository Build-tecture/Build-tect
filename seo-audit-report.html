Remaining Findings (all non-blocking)

1. Images not lazy-loaded & no modern formats Medium

Impact: Core Web Vitals (LCP), especially on image-heavy project/package pages. Evidence: 0 of 244 <img> use loading="lazy"; ~98 JPGs, no WebP. Fix: add loading="lazy" + decoding="async" to below-the-fold images; convert large photos to WebP/AVIF; set explicit width/height to avoid layout shift.

2. Service pages missing from primary nav Medium

Impact: Buries commercially valuable pages; weaker internal link equity. Evidence: header nav = Home/About/Projects/Packages/Blog/Contact; /services only linked in footer. Fix: add Services (or a dropdown) to the header nav.

3. Generic social share image Low

Evidence: og:image = /favicon.jpg (logo on black). Fix: add a dedicated 1200×630 branded share image; ideally per-section.

4. Home meta description slightly long Low

Evidence: 164 chars (may truncate in SERP). Fix: trim to ~150–155.

5. Empty sameAs & no author pages Low

Fix: populate social URLs in the JSON-LD; add blog author bylines/pages for E-E-A-T.
